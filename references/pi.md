# Pi 适配

仅在当前宿主是 Pi coding agent 时读取；流程与授权以 `SKILL.md` 为准。

## 提问

技术地图生成后、规划方向前，用当前会话的 `question` 扩展询问已有知识；选择、单元掌握评估和课程结束评估也用该扩展，失败即停止决策。问题和选项必须参考技术地图中的方向、前置、边界和成本，只问直接影响学习的信息。按专业知识与当前水平调整术语、前置、示例和讲解深度；每个单元讲解后先等待学习者阅读，再用与该单元目标直接相关的问题评估掌握程度并重新校准讲解程度。课程结束后评估整体掌握度，再选择开始新课或深化当前内容；不调用 `ctx.ui.*`。

## 执行

按实际暴露使用 `read`、`bash`、`edit`、`write`、`grep`、`find`、`ls`；`bash` 仅用于练习和探测。Pi 没有核心沙箱，Web/MCP/LSP/todo/subagent 只在扩展注册时存在，不自动安装。先依据初始请求和可用的外部访问用实际 Web/页面读取扩展按[技术地图格式](technology-map-format.md)建图，诊断已有知识后再选路；范围不足或未核实即停止。显式调用：`/skill:daxue-zhidao`；修改后 `/reload`。
