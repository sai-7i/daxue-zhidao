# 课程计划文件格式

仅在创建、检查或更新计划时读取本文件。默认文件名为 `COURSE_PLAN.md`，学习者可指定路径；课程必须创建
计划文件。首次设置边界发生在主题、计划路径、诊断和起始单元均已确认之后、教学之前；此时创建计划。
恢复边界发生在学习者确认重新开启已完成课程之后、教学之前；此时把课程状态改为 `进行中`。

## 状态与结构

课程状态只能是：`进行中`、`已完成`。
单元状态只能是：`进行中`、`已完成`。

计划只保留课程相关且会影响后续教学的完整信息，按此顺序组织：

1. 头部快照：标题、课程状态、计划路径和一句教学规则。
2. 当前环境快照：只记录当前方向仍需要的环境和核实日期。
3. 概览快照：`编号 | 单元 | 状态 | 已确认的能力`。
4. 需求快照：学习者提供的目标、场景、基础、约束、偏好、资源、授权和评估信息。
5. 当前检查点快照：当前方向、该方向的需求依据、待解决问题、当前单元、下一单元和下一方向。

所有章节都是可变快照，不创建追加式历史章节。已完成单元只在概览中保留一行和已确认能力。

## 头部模板

```markdown
# <课程标题>

- 课程状态：<进行中/已完成>
- 计划路径：<COURSE_PLAN.md 的路径>
- 教学规则：一次只学习并验证一个单元。
```

## 需求快照

```markdown
## 学习者需求

- 现实目标：
- 目标场景与最终产出：
- 成功标准与评估方式：
- 已掌握的相关技巧与熟练程度：
- 当前基础与相关经验：
- 当前困难与待解决问题：
- 时间、环境、资源与其他约束：
- 学习与反馈偏好：
- 已授予的授权范围：
```

只记录学习者明确提供或授权实测得到的课程相关信息。后续明确选择与此前信息冲突时，以最后一次明确选择为准，
更新对应字段并删除被取代内容，不保留冲突状态；无法确定先后时才询问。

## 当前环境模板

没有安全实测的值须标明状态，不得根据常识补全。保存前向学习者展示摘要；只保留当前方向必需的项目。

```markdown
## 当前环境

- 核实时间：<ISO 日期或日期时间>
- 系统：<课程需要时填写；值与探测方式>
- 课程目录：<经确认的路径>
- 项目上下文：<相关项目类型和清单文件>

| 工具 | 版本或状态 | 探测方式 | 课程用途 |
| --- | --- | --- | --- |
| <工具> | <版本/未安装/探测失败/未检查> | `<只读命令或文件>` | <为何需要> |
```

不保存秘密、认证内容、完整环境变量或无关个人信息。敏感配置确有课程用途时只记 `已配置`、`未配置` 或
`未检查`。切换方向时直接替换当前方向、方向需求和相关环境快照，不保留旧方向。

## 当前检查点模板

```markdown
## 当前检查点

- 当前方向：
- 方向需求：<从需求快照中提取的、影响当前方向的完整依据>
- 待解决问题：
- 当前单元：<目标、成功标准、必要观察>
- 下一单元：<尽可能多的未完成单元；学习者明确选择后直接开始>
- 下一方向：<尽可能多的未覆盖方向；当前方向必要单元全部完成后提供；学习者选择后须先询问该方向需求>
```

方向需求保留影响当前方向的完整信息；每次进入新方向前都必须重新询问，不沿用其他方向的假设。观察只保留
能证明成功标准的事实，完成后把结论合并到概览并清理当前单元细节。已完成单元不得再次列为候选教学单元。

## 维护检查

- 每次写入前先重整文件：删除秘密、认证内容、无关信息和已被新结论替代的内容；保留所有仍影响后续教学的需求、
  选择、约束、偏好、授权、环境事实、当前方向、已确认能力、当前单元成功标准与观察证据、下一单元和下一方向。
- 学习者后续明确选择与既有信息冲突时，以最后选择为准，更新需求快照、当前方向和检查点，并删除被取代内容。
- 只在首次设置边界、恢复边界、方向边界或单元边界写入；头部、环境、概览和检查点必须保持一致。方向或单元
  边界记录后课程保持 `进行中`，在当前检查点留下待学习者选择的候选并停止本轮教学，不开始第二个单元，也不写入暂停状态。
- 会话开始检查关键字段、课程状态、连续编号、环境适用性和当前检查点，再复述当前状态。`已完成` 课程须确认
  重新开启后才能继续。
- 版本敏感单元只刷新失效或缺失的必要环境项。
- 生成候选前对照概览；排除已完成单元。当前方向的必要单元全部完成时，才生成新的方向选择。
- 写入前重新读取并合并外部新增内容；无法安全合并时停止并询问。合并后仍须再次精简。
- 学习者取消整门课程时删除课程计划文件，不写入 `已取消` 状态；取消或跳过单元时删除该单元记录，清空当前
  单元，重新整理下一选择并保持单元编号连续。
- 只有学习者确认课程目标已达成或明确结束课程时，才把课程状态改为 `已完成`；已完成课程必须经过重新开启
  确认才能继续。
