# 课程计划文件格式

仅在创建、检查或更新 `COURSE_PLAN.md` 时读取。缺失则创建；保留会改变方向、课次或地图范围的结论。六个模块不可改名、合并或重排。

```markdown
# <课程标题>

## 课程状态

- 状态：<进行中/已完成>

## 任务

- 现实目标：<要完成的现实任务和使用场景>
- 路线目标：<方向选择要达成的范围>

## 约束

- <学习者确认的时间、偏好、授权、环境或风险；每条独立记录>

## 地图

- 技术地图：`TECHNOLOGY_MAP.md`（研究日期：<YYYY-MM-DD>）
- 当前课地图：`LESSON_MAP.md`（研究日期：<YYYY-MM-DD>；无当前课则省略）

## 已有知识

- <影响方向或课次范围的专业知识与经验>

## 检查点

- 当前方向：<当前方向；无则省略>
- 当前课：<当前课；无则省略>
- 方向依据：<当前方向的选择依据>
- 课次规划：<介绍、目标、前置、顺序、边界、成本和扩展>
- 用户问题：<影响方向、课次或深入范围的问题；没有则省略>
- 下一选择：<当前方向、课程或扩展候选>
```

`地图` 只引用地图。写入前删除重复、过期和详细内容，保留约束。建图后诊断已有知识；选课后生成课次地图，只给介绍与规划。仅按学习者请求评估路线、方向或深入范围。取消整课时删除计划和地图；仅学习者确认目标达成或结束时标记 `已完成`。
