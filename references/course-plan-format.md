# 课程计划文件格式

仅在创建、检查或更新计划时读取本文件。默认文件名为 `COURSE_PLAN.md`，学习者可指定路径；临时模式不创建
文件。首次设置边界发生在主题、存储模式、诊断和起始单元均已确认之后、教学之前；此时可创建计划。
恢复边界发生在学习者确认继续已暂停课程或重新开启终止课程之后、教学之前；此时把课程状态改为 `进行中`。

## 状态与结构

课程状态只能是：`进行中`、`已暂停`、`已完成`、`已取消`。
单元状态只能是：`已完成`、`未通过`、`已暂停`、`被阻塞`、`已跳过`、`已取消`。

计划按以下顺序组成：

1. 头部快照：标题、课程状态、存储模式、计划路径和一句教学规则。
2. 当前环境快照：只记录课程依赖的环境、探测方式和核实日期。
3. 概览快照：`编号 | 单元 | 状态 | 已确认的能力`。
4. 单元历史：追加式，最新在底部。
5. 更正历史：追加式，写明旧结论、原因、依据和日期。
6. 路线调整历史：追加式，记录切换原因、保留能力、约束和新目标。
7. 当前检查点快照：当前路线、诊断依据、待解决问题和下一步选择。

头部、环境、概览和检查点是可变快照；单元、更正和路线调整历史只能追加。

## 头部模板

```markdown
# <课程标题>

- 课程状态：<进行中/已暂停/已完成/已取消>
- 存储模式：<当前项目/指定位置>
- 计划路径：<COURSE_PLAN.md 的路径>
- 教学规则：一次只学习并验证一个单元。
```

## 当前环境模板

没有安全实测的值须标明状态，不得根据常识补全。保存前向学习者展示摘要。

```markdown
## 当前环境

- 核实时间：<ISO 日期或日期时间>
- 系统：<课程需要时填写；值与探测方式>
- 课程目录：<经确认的路径>
- 项目上下文：<相关项目类型和清单文件>

| 工具 | 版本或状态 | 探测方式 | 课程用途 |
| --- | --- | --- | --- |
| <工具> | <版本/未安装/探测失败/未检查> | `<只读命令或文件>` | <为何需要> |
```

不保存秘密、认证内容、完整环境变量或无关个人信息。敏感配置确有课程用途时只记 `已配置`、`未配置` 或
`未检查`。切换方向引入新工具链时更新快照，并在路线调整历史说明变化。

## 路线调整模板

新课程不创建路线调整记录；切换已有课程方向时追加：

```markdown
## 路线调整 — <日期或检查点>

- 原方向：
- 切换原因：
- 保留的能力与进度：
- 新方向目标：
- 新约束或环境：
- 诊断依据：
- 已选择的起始单元：
```

## 单元模板

```markdown
## <状态>：单元 N — <标题>

- 你选择的方向：
- 开始前目标：
- 成功标准：
- 练习或命令：
- 观察结果：
- 已确认的结论：
- 你的关键判断：
- 未确认或阻塞原因：
- 下一检查点：
```

编号使用连续整数。观察只记事实，结论由事实推出；只有观察满足成功标准才记 `已完成`。非完成状态必须
写原因，无结论的字段写“无”。

## 当前检查点模板

```markdown
## 当前检查点

- 当前路线：
- 诊断依据：<影响初始或当前路线的回答摘要>
- 待解决问题：
- 下一步选择：<2–3 个方向，或已获得的默认继续授权>
```

诊断依据只保留影响路线的信息。新课程和方向切换未完成诊断时不得开始教学。

## 维护检查

- 只在首次设置边界、恢复边界或单元边界写入；概览、历史和检查点保持一致。
- 会话开始检查关键字段、课程状态、连续编号、环境适用性和当前检查点，再复述当前状态。`已暂停` 须确认
  继续；`已完成` 或 `已取消` 须确认重新开启或新建课程。
- 版本敏感单元只刷新失效或缺失的必要环境项。
- 写入前重新读取并保留外部新增内容；无法安全合并时暂停并询问。
