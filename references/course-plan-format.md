# 课程计划文件格式

仅在创建、检查或更新计划时读取本文件。默认文件名为 `COURSE_PLAN.md`，学习者可指定路径；课程必须创建
计划文件。首次设置边界发生在主题、计划路径、诊断和起始单元均已确认之后、教学之前；此时创建计划。
恢复边界发生在学习者确认重新开启已完成课程之后、教学之前；此时把课程状态改为 `进行中`。

## 状态与结构

课程状态只能是：`进行中`、`已完成`。
单元状态只能是：`进行中`、`已完成`。

计划只保留以下最小内容，按此顺序组织：

1. 头部快照：标题、课程状态、计划路径和一句教学规则。
2. 当前环境快照：只记录当前方向仍需要的环境和核实日期。
3. 概览快照：`编号 | 单元 | 状态 | 已确认的能力`。
4. 当前检查点快照：当前方向、该方向的需求依据、待解决问题、当前单元和下一方向。

所有章节都是可变快照，不创建追加式历史章节。已完成单元只在概览中保留一行和已确认能力。

## 头部模板

```markdown
# <课程标题>

- 课程状态：<进行中/已完成>
- 计划路径：<COURSE_PLAN.md 的路径>
- 教学规则：一次只学习并验证一个单元。
```

## 当前环境模板

没有安全实测的值须标明状态，不得根据常识补全。保存前向学习者展示摘要；只保留当前方向必需的项目。

```markdown
## 当前环境

- 核实时间：<ISO 日期或日期时间>
- 系统：<课程需要时填写；值与探测方式>
- 课程目录：<经确认的路径>
- 项目上下文：<相关项目类型和清单文件>

| 工具 | 版本或状态 | 探测方式 | 课程用途 |
| --- | --- | --- | --- |
| <工具> | <版本/未安装/探测失败/未检查> | `<只读命令或文件>` | <为何需要> |
```

不保存秘密、认证内容、完整环境变量或无关个人信息。敏感配置确有课程用途时只记 `已配置`、`未配置` 或
`未检查`。切换方向时直接替换当前方向、方向需求和相关环境快照，不保留旧方向。

## 当前检查点模板

```markdown
## 当前检查点

- 当前方向：
- 方向需求：<该方向的目标、相关基础和约束摘要>
- 待解决问题：
- 当前单元：<目标、成功标准、必要观察>
- 下一方向：<2–3 个未覆盖方向；选择后须先询问该方向需求>
```

方向需求只保留影响当前起点的最少信息；每次进入新方向前都必须重新询问，不沿用其他方向的假设。观察只保留
能证明成功标准的事实，完成后把结论合并到概览并清理当前单元细节。已完成单元不得再次列为候选教学单元。

## 维护检查

- 每次写入前先重整文件：删除过时、重复、无关和已被新结论替代的内容；只保留当前方向、该方向的需求依据、
  已确认能力、当前单元成功标准与观察证据、下一方向。
- 只在首次设置边界、恢复边界或单元边界写入；头部、环境、概览和检查点必须保持一致。单元边界记录后课程
  保持 `进行中`，等待学习者下一次输入，不写入暂停状态。
- 会话开始检查关键字段、课程状态、连续编号、环境适用性和当前检查点，再复述当前状态。`已完成` 课程须确认
  重新开启后才能继续。
- 版本敏感单元只刷新失效或缺失的必要环境项。
- 生成候选前对照概览；排除已完成单元。当前方向没有必要补强时，立即生成新的方向选择。
- 写入前重新读取并合并外部新增内容；无法安全合并时停止并询问。合并后仍须再次精简。
- 取消整门课程时删除课程计划文件，不写入 `已取消` 状态。
