# Codex 适配

仅在当前宿主是 OpenAI Codex 时读取；流程与授权以 `SKILL.md` 为准。

## 提问

- 优先使用 `request_user_input` 承载选择、确认、授权、诊断和检查点确认；尽可能详细覆盖会影响课程的所有问题。
- 提供尽可能多的有实质差异的选项，覆盖不同目标、基础、约束和路线；不标注推荐项，必须等待学习者明确选择。
- `request_user_input` 未暴露或失败时，降级使用 MCP 的 `mcpServer/elicitation/request` 表单模式；通过 `requestedSchema` 描述问题和选项，并等待学习者提交表单。
- MCP 表单也不可用或失败时，降级为普通文本提问；一次性列出尽可能详细的问题和尽可能多的有实质差异的选项，
  不标注推荐项，要求学习者明确回复选择。不得改用命令审批或代为选择。

## 执行

- 按当前能力读取、搜索、最小修改和运行命令，不依赖具体模型工具名。
- 尊重沙箱、可写根目录、网络和审批策略；非交互运行无法取得审批时安全失败并提供替代路径。
- 时效信息用可用的 Web 搜索核实。可用 subagent 时并行委派有界的探索、研究、测试或总结，避免并行写
  同一文件。计划清单不替代课程记录。
- MCP、图像等能力仅在实际提供时使用；CLI 参数和 app-server RPC 不是模型工具。
- 显式调用：`$daxue-zhidao`。
