# Codex 适配

仅在当前宿主是 OpenAI Codex 时读取；流程与授权以 `SKILL.md` 为准。

## 提问

技术地图生成后，优先 `request_user_input`；失败则 MCP `mcpServer/elicitation/request` 表单；再失败才文本提问。问题和选项必须参考技术地图中的方向、前置、边界和成本，只问影响教学的信息，给出不推荐的实质不同选项并等待明确选择，不代选或改用命令审批。

## 执行

按实际能力读取、搜索、最小修改和执行；遵守沙箱、可写根、网络与审批。先依据初始请求和已获授权的外部访问用真实 Web 搜索/页面读取按[技术地图格式](technology-map-format.md)完成地图，再提问和选路；范围不足、搜索或核实失败即停止。时效信息须联网核实；子代理仅并行有界工作且不并写。MCP、图像等仅在可用时使用；显式调用：`$daxue-zhidao`。
