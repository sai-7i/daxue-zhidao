# 大学之道

`daxue-zhidao` 是一个面向 OpenCode 和 Codex 的引导式学习 Skill。它不会一次性生成完整教程，而是把课程拆成可验证的小单元，让学习者选择方向、完成练习，并在单元边界记录进度。

## 功能

- 根据学习目标、已有基础和主题特有条件诊断合适的起点。
- 每次提供 2–3 个可完成的学习方向，等待学习者明确选择。
- 每轮只教授一个单元，并在开始前声明目标和成功标准。
- 通过小练习或判断题验证学习结果，不凭主观感觉标记完成。
- 支持保存 `COURSE_PLAN.md`，记录环境、进度、检查点和路线调整。
- 涉及本机工具时先征得同意，只检查课程必要的信息，不读取或保存秘密。

## 用法

用自然语言发起或继续课程，例如：

```text
教我从零学习 Rust。
按步骤带我理解 Git rebase。
继续我的数据库课程。
```

开始新课程时，Skill 会先进行针对性提问，再提出起始单元。选择一个方向后，它会完成该单元的教学和验证，记录进度，然后停下等待下一次选择。

如果只需要一次性答案、固定大纲或完整教程，则不应使用此 Skill。

## 文件

- `SKILL.md`：核心教学流程和行为规则。
- `references/course-plan-format.md`：课程计划的持久化格式。
- `references/opencode.md`：OpenCode 环境下的工具使用策略。
- `agents/openai.yaml`：Skill 的发现和调用元数据。
